In Part 5 I called my handwritten daily list a bypass around my own system. This week the system adopted it.

## It opens on my list

Every session used to start with a long agenda: everything overdue, everything coming up, every open decision. I never read it. I read my handwritten list. So a new session now opens on that list alone, the handful of lines I chose for the day. The full agenda is still there if I ask. What I see first went from about eight thousand characters to one thousand.

## It reaches my phone

The system now runs on a spare computer at home that never switches off. I can message it from my phone, typing or dictating, and it works on the same files. Today I wrote a paragraph on top of my list saying what mattered most, sent one message, and the list came back reordered. It cannot send email: anything for another person arrives as a draft. Each morning at seven my list for the day lands on my phone.

## It closes the day

At five to midnight it logs what I ticked off, writes the day's summary and adds my reflection. The first version of that summary ran to eleven paragraphs. I only read it the next morning to get back into the work, so the rule is now one phone screen. The log keeps the detail.

All of this is a day old, and the first overnight run is tonight. The rule from Part 5 still holds: it only does what I can undo. It also sends me one line each night saying what it did, and if that line stops arriving I will know the day it fails.
